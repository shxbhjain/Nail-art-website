Site Overview

A fully responsive luxury nail art studio website built with React + Vite + Framer Motion. The design follows a sophisticated editorial aesthetic with warm ivory palette, elegant serif typography, and intentional whitespace.

Key Features

Editorial Design System

Warm ivory palette with elegant serif typography, generous whitespace, and intentional visual hierarchy

Interactive Gallery

Asymmetrical grid layout with lightbox functionality and mood-based filtering system

Smooth Animations

Framer Motion-powered transitions with slow, elegant timing (400-800ms)

Component Architecture

  • Navbar - Sticky navigation with mobile hamburger menu
  • Hero - Editorial hero section with dual CTAs and scroll indicator
  • FeaturedWork - Gallery with lightbox and asymmetrical grid layout
  • Services - Four premium service cards with hover animations
  • MoodFilter - Interactive mood-based gallery filtering
  • About - Split layout about section with brand philosophy
  • Testimonials - Carousel with client reviews and navigation
  • SocialGallery - Instagram-style social feed
  • BookingCTA - Final call-to-action section
  • BookingModal - Complete appointment booking form
  • Footer - Site footer with navigation, contact, and social links

Design System

Colors: Ivory (#FAF8F5), Warm White (#F5F3EF), Beige (#E8E3DC), Taupe (#C9C0B5), Blush (#D4B5A8), Espresso (#3A2F2B)

Typography: Cormorant Garamond (serif headings), Inter (sans-serif body)

Transitions: Slow, elegant animations (200-800ms) with consistent easing

Spacing: Consistent spacing scale with generous whitespace
