# LUNE NAILS — Premium Nail Art Website

A luxury nail art studio website built with React, Vite, and Framer Motion. Features an editorial aesthetic, sophisticated animations, and a premium user experience.

## ✨ Features

- **Editorial Design System**: Warm ivory palette with elegant serif typography
- **Interactive Gallery**: Asymmetrical grid layout with lightbox functionality
- **Mood-Based Filtering**: Filter nail designs by aesthetic mood
- **Smooth Animations**: Powered by Framer Motion for elegant transitions
- **Booking Modal**: Complete appointment booking interface
- **Testimonial Carousel**: Client reviews with smooth transitions
- **Fully Responsive**: Optimized for desktop, tablet, and mobile
- **Accessible**: Keyboard navigation and focus states throughout

## 🎨 Design System

- **Sans**: Inter (Body text)

## 🚀 Getting Started

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
